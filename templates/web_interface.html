     About Artwork Uploader for Plex

    Version:

    Artwork Uploader for Plex is an open-source application written in Python and designed to simplify the process of managing artwork for your Plex media server. Whether you're looking to enhance your movie posters, TV show covers, episode title cards or collection artwork, this tool provides an easy-to-use interface to streamline the process.
